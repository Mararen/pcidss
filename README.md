--PCI-Cert Pro es una plataforma web desarrollada para facilitar y automatizar el proceso de autocertificación bajo el estándar PCI DSS v4.0.1, dirigida a comercios y proveedores de servicios de nivel 2, 3 y 4.

La aplicación permite a las organizaciones:
-Realizar un prediagnóstico de cumplimiento.
-Completar el cuestionario SAQ correspondiente.
-Gestionar y organizar evidencias documentales.
-Generar un certificado digital de cumplimiento.
-Dar seguimiento al estado de su proceso de autocertificación.

El sistema está diseñado para apoyar el cumplimiento normativo sin requerir obligatoriamente la participación de un QSA externo, conforme a la normativa vigente.

--Arquitectura y Tecnologías

El sistema implementa una arquitectura modular basada en:

-Python
-Django
-PostgreSQL


--Requisitos del Sistema

-Python 3.x
-PostgreSQL
-pip
-Entorno virtual (recomendado)
